Nogoon · Windows

Depuis la sortie de la version 0.2.0

Téléchargements = navigateurs distincts ayant demandé le fichier, sans preuve que le transfert est terminé. Ouvertures et installations = profils Windows distincts. Ces deux groupes ne sont pas reliés individuellement : le ratio est indicatif. Une installation passée du gratuit au permanent figure dans les deux catégories, mais une seule fois dans le total.

Les échecs signalés commencent après l’ouverture de l’app. Les blocages avant ouverture ne sont visibles que dans l’écart entre les compteurs ou dans les réponses à l’aide d’installation. Un faible ratio ne permet pas, à lui seul, d’attribuer les abandons à SmartScreen.
