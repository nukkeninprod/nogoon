Install Nogoon for Windows

Start your free 72-hour block. Windows 10 or 11, 64-bit.

Download for Windows

Version 0.2.0 · One-time payment inside the app to keep the block permanently.

  1. Open Nogoon-Setup-0.2.0.exe from your Downloads folder.
  2. Follow the installer, then open Nogoon.
  3. Save your work in your browser, choose the free block or enter your paid license, and accept the Windows administrator prompt.

Does Windows say “Windows protected your PC”?

This release is unsigned, so Windows may show a SmartScreen warning. If you downloaded the installer using the link on nogoon.io, select More info, then Run anyway.

If Windows shows a different warning or does not offer that option, contact support@nogoon.io with the message you see.
